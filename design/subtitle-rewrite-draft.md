# 字幕改写草稿(2026-10-14)

用户试玩反馈:「改字幕,AI 味太重」。用户选「全部重写草稿」:40 句左右逐句给改写,新旧并排,用户逐句挑。
**还没改进游戏** —— 用户定了哪几句,再改关卡描述 / 配置、重建、跑检查。

`叙事脚本.md` 是锁定文件,不改;游戏里的句子定稿后记在 `design/ideas-backlog.md`,注明和锁定剧本不同。

## AI 味从哪来(这次改的方向)

| 毛病 | 例子 | 改法 |
|---|---|---|
| 几乎每句都有「……」「——」 | 「螺母。……够响了。」 | 只在真的停顿、说不下去时用;一关最多一两处 |
| 金句 / 对仗 / 反转 | 「小时候以为塔顶是天。……其实只是更高的墙。」 | 换成具体的东西、具体的事 |
| 替玩家讲机制 | 「头盔把眼睛都封了……他是靠耳朵的。」 | 只说看到的,让玩家自己想 |
| 书面、端着 | 「可她就在禁止的里面。」「不是结束。是终于被允许休息。」 | 口语、短,像一个十几岁的妹妹会说的 |
| 前后呼应太工整 | 「他们漏了我。……这次我也漏过去。」 | 留一半,不把扣子扣死 |
