# 试玩怎么记(2026-10-14)

试玩的人**只管玩**,不用边玩边记笔记。游戏自己记,玩完出报告和每关的热点图。

## 玩

1. 打开 Godot 编辑器,按 **F5**(运行项目),从主菜单开始玩。
2. 想停就停:暂停不计时;关掉游戏也行,下次接着玩会记成新的一段,报告里会合起来算。
3. 能玩多远玩多远。卡住、觉得不公平、觉得好玩的地方,如果想说,玩完口头说一句就好 —— 数字报告会告诉我们**在哪里**,
   你的感觉告诉我们**为什么**。

记录在 `~/Library/Application Support/Godot/app_userdata/The Cradle/playtest/`,一次运行一个 `.jsonl` 文件。

## 出报告

```bash
python3 tools/playtest/report.py --since 2026-10-14
```

输出:

- `production/qa/playtest-<日期>.md`:每关用时、被发现几次 / 被谁 / 当时在干嘛 / 在不在暗处、守卫起疑、
  存档点之间用时、重生后 5 秒内又被抓、和机器人体检(`pacing-*.json`)对照、对照 L1 / K3 / K5
- `production/qa/playtest-<日期>/<场景>.png`:热点图。青 = 走过的地方(越亮待得越久)· 红 × = 被发现(细线连到抓人的守卫 / 灯)·
  黄点 = 守卫起疑 · 绿菱形 = 踩到的存档点 · 白点 = 丢扣件

报告**只有观察,没有结论**:标出来的是「值得看一眼」,难不难、要不要改,由试玩的人定。

## 记了什么

`src/dev/playtest_log.gd`(autoload `PlaytestLog`)。一行一个事件,写完就存盘(闪退也不丢):

| 事件 | 内容 |
|---|---|
| `session` / `end` | 开始时间、Godot 版本 |
| `enter` / `leave` | 进 / 出哪个场景,这关被发现几次 |
| `pos` | 每 0.25 秒:Ryn 的位置、在干嘛(站 / 走 / 跑 / 蹲 / 蹲着走 / 爬梯 / 躲着 / 空中 / 瞄准)、在不在暗处 |
| `cp` | 踩到哪个存档点 |
| `fail` | 被发现:位置、被谁(「看」「听」「追」的守卫 / 探照灯 / 门禁灯 / Vera)和它的位置、Ryn 在干嘛、在不在暗处、上一个存档点、离上次重生几秒 |
| `respawn` | 回到存档点、交还控制 |
| `alert` | 守卫从巡逻变成起疑(头上「?」)—— 差点被发现 |
| `throw` / `hide` / `unhide` | 丢扣件、进出柜子 / 通风管 |

时间按物理帧算真实秒数,暂停不算(被发现时的顿帧不会让时间少算)。

## 什么时候不记

- `-s` 检查脚本、`--demo=` 路线机器人:不记(会把数据搅乱)。
- 强制开 / 关:`godot --path . -- --playtest-log` / `-- --no-playtest-log`。
- 导出的正式版(非 debug):不记。

检查:`godot --path . --headless --fixed-fps 60 -s res://src/dev/playtest_check.gd`(23 项)。
