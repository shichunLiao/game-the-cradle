The Cradle — 試玩版(版本 {VERSION},{DATE})

【怎麼開】
1. 先把整個壓縮檔「解壓縮」,不要在壓縮檔裡直接點開。
2. 雙擊 TheCradle.exe。
3. 如果跳出藍色的「Windows 已保護您的電腦」:按「其他資訊」→「仍要執行」。
   (遊戲沒有付費的程式簽章才會這樣,不是病毒。)

【操作】          鍵盤                    手把
移動              A D 或 ← →              十字鍵
爬梯              W / S 或 ↑ / ↓          十字鍵上下
蹲下              S 或 ↓                  十字鍵下
跳                空白鍵 或 K             A
跑                Shift 或 Ctrl           RB
互動 / 按住拆東西  E                       X
丟扣件            按住 F 瞄準,A D 調落點,放開丟出    按住 Y
暫停 / 設定 / 改按鍵  Esc                  Start
全螢幕            F11(或 F9、Alt+Enter)

【存檔】
存檔和設定在:%APPDATA%\Godot\app_userdata\The Cradle\
想從頭玩,把這個資料夾刪掉就好。

【回饋】玩完請告訴我們:
- 玩到哪一關、大概玩了多久?
- 在哪裡卡住、被抓最多次?
- 哪裡覺得不公平?哪裡覺得好玩?
- 如果出錯或閃退:請把 %APPDATA%\Godot\app_userdata\The Cradle\logs\ 裡最新的檔案一起傳回來。
